## 🚀 Featured Projects

### 🌱 Smart Precision Drip Irrigation & Crop Yield Determination using IoT and AI
Built an ESP32-based IoT smart irrigation system with sensor-based automated drip irrigation. Developed an AI-powered crop recommendation system providing yield, profit, and fertilizer insights through a web dashboard.

**Technologies:** ESP32 • IoT • Sensors • AI/ML • Web Dashboard

---

### 🩺 Disease Diagnosis using Binary Tree & Symptoms
Developed a disease diagnosis system using C and HTML to identify potential illnesses based on user-provided symptoms. Features an interactive interface for intuitive symptom input and clear visual results, with binary tree logic used to efficiently process symptoms and match possible conditions.

**Technologies:** C • HTML • Binary Trees • Data Structures

---

### 🧒 AI-Based Early Malnutrition Risk Prediction System for Anganwadi Children
Built a full-stack web application using Python, Flask, MySQL, and Scikit-learn's Random Forest algorithm to predict early malnutrition risk in Anganwadi children. Includes a complete Tamil language interface designed to improve accessibility for rural communities.

**Technologies:** Python • Flask • MySQL • Scikit-learn • Random Forest • HTML/CSS • Tamil UI
